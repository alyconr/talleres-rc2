# T001 — Escenarios y criterios de comparación

## Pregunta

Para el MVP de talleres de motos en Colombia, ¿conviene conectar cada taller directamente a WhatsApp Cloud API o usar Twilio o 360dialog como proveedor intermediario?

## Escenarios de referencia

Son unidades normalizadas para comparar alternativas, no una proyección de demanda ni una decisión de volumen comercial:

- **Bajo:** 100 citas confirmadas/mes, 100 plantillas de utilidad para confirmación, hasta 200 mensajes entrantes de clientes y hasta 200 respuestas de servicio libres.
- **Medio:** 1.000 citas confirmadas/mes, 1.000 plantillas de utilidad para confirmación, hasta 2.000 mensajes entrantes y hasta 2.000 respuestas de servicio libres.
- Se asume que el cliente inicia o mantiene la conversación dentro de la ventana aplicable para los mensajes de servicio. Si la política o los precios vigentes invalidan este supuesto, la comparación lo señalará.
- El cálculo debe separar mensajes de plantilla facturables, mensajes de servicio, cargos de Meta trasladados por el BSP, cargos adicionales del BSP, tarifas fijas y costos operativos internos. No se asume que una tarifa publicada incluya las demás.

## Criterios

1. Disponibilidad y requisitos para empresas y números colombianos.
2. Alta/autoservicio de talleres: Embedded Signup, verificación, propiedad del número y administración de varias cuentas.
3. Mensajería: API, plantillas, categorías, ventana de servicio, límites y capacidades relevantes.
4. Webhooks: firma/autenticación, reintentos, idempotencia, orden y observabilidad.
5. Aislamiento multitenant: asignación de credenciales, asociación de números a taller y riesgo de acceso cruzado.
6. Costos bajo escenarios bajo/medio, con fuente y fecha por componente.
7. Soporte, SLA publicado, dependencia del proveedor y esfuerzo de operación/migración.
8. Encaje con el módulo hexagonal de conversaciones y RabbitMQ descritos en `docs/ARCHITECTURE.md`.

## Regla de evaluación

No asignar puntuaciones numéricas si no hay evidencia comparable. Usar evidencia oficial fechada; marcar cada dato no publicado o no confirmado para Colombia como "no verificado". La recomendación debe indicar confianza y las condiciones que la cambiarían.
